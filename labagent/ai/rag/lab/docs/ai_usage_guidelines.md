# Acme Corp Generative AI Usage Guidelines

## Approved tools

Employees may use only AI tools on the approved list kept by IT. As of this version the list contains the internal
assistant, the code assistant licensed by the engineering team, and the meeting summarizer. Free consumer chatbots are not
approved for any company work.

## What may be entered

Public and Internal data may be used with any approved tool. Confidential data may be used only with the internal
assistant, which does not send data outside the company. Restricted data, including customer records, payment data and
employee records, must never be entered into any AI tool.

## Review of output

AI output is a draft. A person must review it before it is sent to a customer, published, or used in a decision about a
person. The reviewer is responsible for its accuracy. Code written with the code assistant goes through the normal code
review.

## Logging

The internal assistant keeps prompts and answers for 30 days so that misuse can be investigated. Employees should not
expect the content to be private from the security team.

## Prohibited uses

Do not use AI tools to make hiring, firing or credit decisions on their own, to create content that imitates a real person
without their consent, or to try to bypass company controls.

## Reporting problems

If an AI tool leaks data or gives a harmful answer, report it to the security desk. Treat it as a security incident.
